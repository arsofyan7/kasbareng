KASBARENG ANTIGRAVITY SPEC PACK
Isi:
- requirements/: file kebutuhan yang dibaca Antigravity sebagai spesifikasi utama.
- project/algorithms/: dokumentasi modul algoritma inti yang dipisahkan untuk kepentingan akademik.
- requirements/IMPLEMENTATION_STATUS.md: template tracking implementasi.

Struktur source code yang disarankan untuk implementasi aktual:
apps/api/src/algorithms/
Dokumentasi di project/algorithms/ disediakan sebagai blueprint. Ketika Antigravity membuat repository aplikasi, salin atau implementasikan algoritma pada folder source code tersebut dengan struktur yang sama.
